3.  “Interested” Column 
Displays bubbles containing the initials of conveyors interested in a task.
Offers a visual cue for engagement.

4.  Assign/Unassign via Bubbles
The user can assign or deassign a conveyor from a task by clicking their bubble.
A confirmation prompt prevents accidental changes.

5.  Assigned Task Counter
Updates in real-time to reflect the number of tasks assigned to each conveyor.
Enhances visibility of workload distribution.

6. Customer recovery 
 Customer recovery is bolded to be easily distinguished from delivery.
